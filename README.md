# AstrBot ImgTag 表情包图库插件

本插件基于 [ImgTag](https://github.com/127Wzc/ImgTag) 项目提供的外部 REST API，将引用消息中的图片上传到 ImgTag 图库，并使用 ImgTag 的 AI 分析生成标签和描述。

当前插件版本：**v1.1.0**。版本变更见 [更新日志](./CHANGELOG.md)。

## ImgTag 版本兼容性

- **ImgTag v0.1.12**：支持本插件的回调模式，也可以使用轮询模式。
- **ImgTag v0.1.12 之前的版本**：仅支持轮询模式，请将插件的 `callback_api_key` 留空。

配置 `callback_api_key` 后，插件会使用回调而不再轮询；旧版 ImgTag 用户请先升级至 v0.1.12，再启用回调。

## 功能

- 仅 AstrBot 识别为管理员的用户可以执行 `/偷图`；非管理员触发时插件不回复。
- 管理员引用一条包含图片的消息后发送 `/偷图`，即可上传引用图片；可以在命令后附加标签。
- 上传后会提示正在解析；配置回调 API Key 时，通过 ImgTag 回调主动推送分析结果，否则轮询获取结果。
- 分析完成后以图片、标签和主体描述组成富媒体消息回复；轮询模式最长等待约 2 分钟，回调模式不受该等待时间限制。
- 回调模式会将原会话保存到插件 KV 存储，重启插件后仍可接收待处理的回调；分析失败时主动发送失败提示。

## 配置

在 AstrBot 插件配置中填写：

- **ImgTag 服务域名**：只填写域名，例如 `https://imgtag.example.com`。插件会自动拼接 `/api/v1/external/images`。
- **ImgTag API Key**：在 ImgTag 用户中心生成的 API Key。插件通过 `X-API-Key` 请求头认证；不要填写登录 JWT。
- **AstrBot 回调接口使用的 API Key**（`callback_api_key`，可选，仅 ImgTag v0.1.12 支持）：在 AstrBot 设置的 OpenAPI 中创建并授予 `plugin` 权限，同时配置 ImgTag 可访问的 `callback_api_base`。填写后，插件上传时携带回调地址及认证头，不再轮询；留空则保留轮询，旧版 ImgTag 必须留空。

回调使用上传时生成的 `request_id` 查询参数定位原会话，请确保反向代理保留完整的回调 URL（包含查询参数）。主动发送是否可用取决于消息平台支持。若未找到原平台或发送抛出异常，待处理记录会保留；再次收到该回调时可重试发送。成功发送后清理记录，重复回调不会重复推送。

轮询和回调中的图片地址均支持完整 HTTP(S) 地址和相对路径（例如 `/data/uploads/meme/example.jpg`）；相对路径会使用配置的 ImgTag 服务域名补全，完整地址保持不变。

## 使用方法

1. 管理员引用一条含图片的消息。
2. 发送 `/偷图 标签1 标签2`，也支持 `/偷图 标签1,标签2` 或 `/偷图 标签1，标签2`。
3. 标签可用空格、英文逗号或中文逗号分隔；插件会将其作为自定义标签上传，同时保留 ImgTag AI 分析。
4. 等待“正在解析中”提示后的富媒体分析结果。

若引用图片没有可直接访问的 HTTP(S) 链接，插件会通过 AstrBot 文件服务提供图片。此时需要配置 `callback_api_base`，并确保 ImgTag 服务可以访问该地址。
